# Internationalisation (i18n) Skill

## Stack (already installed)

- `symfony/translation` — translation component
- `symfony/intl` — locale-aware date/number formatting

## Config

```yaml
# config/packages/translation.yaml
framework:
    default_locale: fr
    translator:
        default_path: '%kernel.project_dir%/translations'
        fallbacks: [fr]
```

## Translation files — YAML format

```yaml
# translations/messages.fr.yaml
participation:
    title: "Soutenir la ruelle d'Adem"
    submit: "Ajouter au panier"
    tier:
        standard: "Participation standard"
        vip: "Participation VIP"
order:
    status:
        pending: "En attente de paiement"
        paid: "Payée"
        failed: "Échouée"
    items: >
        {count, plural,
            =0    {Panier vide}
            one   {1 article}
            other {# articles}
        }

nav:
    home: "Accueil"
    participate: "Participer"
    gallery: "Galerie"
    who: "Qui est Adem ?"
    press: "Presse"
    login: "Connexion"
    logout: "Déconnexion"
```

## Twig usage

```twig
{# Simple translation #}
{{ 'participation.title'|trans }}

{# With parameters #}
{{ 'order.items'|trans({'count': cart.itemCount}) }}

{# Date formatting (Intl) #}
{{ order.paidAt|format_date('long', locale='fr') }}
{# → "10 mai 2026" #}

{# Relative time #}
{{ order.paidAt|format_datetime('relative_short', locale='fr') }}
{# → "il y a 2 jours" #}
```

## PHP usage

```php
use Symfony\Contracts\Translation\TranslatorInterface;

public function __construct(private readonly TranslatorInterface $t) {}

$message = $this->t->trans('order.confirmation.subject', ['name' => $name]);
```

## Domain Enums with labels

```php
enum OrderStatus: string {
    case Pending = 'pending';
    case Paid    = 'paid';
    case Failed  = 'failed';

    public function label(): string {
        return match($this) {
            self::Pending => 'En attente',
            self::Paid    => 'Payée',
            self::Failed  => 'Échouée',
        };
    }
}

// In Form: 'choice_label' => fn(OrderStatus $s) => $s->label()
// In Twig: {{ order.status.label() }}
```

> For user-facing labels, prefer translation keys (`order.status.paid`) over hardcoded
> strings so FR/EN/NL stay in sync; the inline `match` above is shown for brevity.

## Translation domains

| Domain | Usage |
|---|---|
| `messages` | General UI |
| `validators` | Validation errors |
| `security` | Auth / login |
| `emails` | Email subjects and bodies |

```yaml
# translations/validators.fr.yaml
"This value should not be blank.": "Ce champ est obligatoire."
"This value is not a valid email address.": "Adresse email invalide."
"This value is too short. It should have {{ limit }} character or more.|This value is too short. It should have {{ limit }} characters or more.": "Ce champ doit contenir au moins {{ limit }} caractères."
```

## Rules

- Default locale = `fr` — this is a French platform
- All user-facing strings in translation files — never hard-coded in PHP/Twig
- ICU message format for plurals — never string concatenation
- Date/number formatting via `symfony/intl`, never `date()` PHP function
- Translation keys: `domain.context.label` (e.g. `order.status.paid`)
- Enum labels defined directly on the Enum as `label()` method, not in translation files
